# 客服工单趋势分析工具

自动从工单数据中发现趋势和异常，帮助客服主管快速定位需要重点关注的问题。使用 Go 语言实现，对 `task5_tickets.json` 中的 50 条工单进行分析，输出结构化的 Markdown 趋势报告和可交互的 HTML Dashboard。

## 快速开始

```bash
go run .            # 或 go build -o ticket-analysis.exe . && .\ticket-analysis.exe
```

输出文件：

- `report.md` — 结构化趋势报告
- `dashboard.html` — 带图表的可视化 Dashboard（用浏览器打开即可）

支持自定义输入文件：`go run . 你的文件.json`

## 分析维度

| 维度 | 说明 | 对主管决策的价值 |
|---|---|---|
| 时间趋势 | 每日工单总量、峰值 | 判断整体业务压力、是否需要增派人手 |
| 类型分布 | 各问题分类的数量、占比 | 明确重点问题域，指导资源倾斜 |
| 严重程度 | 高/中/低优先级、平均处理时长、满意度 | 识别处理瓶颈与用户痛点 |
| 关联关系 | 分类 × 优先级、渠道分布 | 理解问题集中在哪些环节（电话/在线） |
| 异常检测 | 分类突增、增长趋势、高危未解决、处理超时、反复出现关键词 | 一键定位「最近什么变多了、哪里要救火」 |

## 关键趋势与异常

1. **支付问题集中爆发（最高优先级）**：支付问题占全量 32%（16/50），其中 14 条为高优先级。后半段（06-08~11）达 13 条，是前半段 3 条的 4 倍，呈明显上升趋势。
2. **重复扣款 / 支付状态不一致是核心痛点**：反复出现「扣款成功但订单未生成」「重复扣款」「金额扣错」等问题，且 T046 明确提到「上个月也有过」——疑似系统级缺陷而非偶发。
3. **退款退货处理严重超时**：平均处理 45.2 小时（全量最长），多条超 72 小时，且有 5 条高优先级未解决（T031/T036/T039/T042/T047）。用户集中抱怨「退货运费垫付未报销」「退款迟迟不到账」。
4. **投诉增长 3 倍**：后半段 3 条 vs 前半段 1 条，满意度 1.0 为所有分类最低，集中在客服态度与机器人体验上。
5. **整体满意度偏低**：平均 2.36/5，且 62% 工单为高优先级，需关注客服体验与服务流程。

## 异常判断依据

- **增长趋势**：比较时间轴前后两半段的分类数量，后半段达到前半段 2 倍以上且差距 ≥2 判定为「增长趋势」；前半段为 0、后半段 ≥2 判定为「分类突增」。
- **高危未解决**：`is_resolved=false` 且 `priority=高`，直接列为需跟进项。
- **处理超时**：`resolution_time_hours > 72`。
- **反复出现**：直接依据 `category` 字段统计各问题类型的出现频次（即高频问题类型），出现次数越多越需优先关注。

├── task5_tickets.json      # 输入工单数据（50 条）

## AI 工具使用情况

本工具的分析逻辑（维度定义、统计聚合、异常检测规则、报告与 Dashboard 生成）由 AI 辅助完成：AI 负责设计分析框架、编写 Go 实现并生成可视化模板，人类负责校验数据字段、审阅异常判定阈值与最终结论。
